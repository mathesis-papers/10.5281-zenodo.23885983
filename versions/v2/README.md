# Resolving User3's orthogonal absolute-product question: minimum and minimizers

**Authors:** Haobo Ma, Wenlin Zhang

We resolve User3's question (question 515549, revision 1, September 25, 2026): for every nonsingular real square matrix of positive size, the orthogonal minimum of rho(|PQ||Q^T P^{-1}|) is attained and equals one. Thus the proposed strict uniform lower bound cannot hold for any such matrix. We give a self-contained exposition of the triangularization proof in the pinned formal source, then characterize every minimizer by independent row and column permutations to triangular form. For fixed P, the set of minimizers is finite and has an explicit description using row-permuted QR factorizations. The same minimum holds over the special orthogonal group. Finally, the companion absolute-row-sum balancing question follows from the Yamabe-Yujobo theorem.
